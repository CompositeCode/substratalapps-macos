# Concepts
{: .no_toc }

The ideas every Hub screen is built on. Read these once and the rest of the app makes sense.
{: .fs-6 .fw-300 }

- [How access works](how-access-works/): whether an app is on for a person, and why.
- [Roles and permissions](roles-and-permissions/): what a person can do, on the platform and inside each app.
- [Applications, keys and webhooks](applications-keys-webhooks/): how an app plugs into the platform.
- [Test mode and live mode](test-and-live-mode/): building safely next to real users.

The full model is in the Platform API specification: [Access Control](https://compositecode.github.io/substratalapps.com/access-control/) and [Domain Model](https://compositecode.github.io/substratalapps.com/domain-model/).
