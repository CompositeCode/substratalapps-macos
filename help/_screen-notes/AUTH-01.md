- Enter your email and password and choose **Sign In** (or press Return).
- **Forgot password?** opens the reset page on the web.
- **Test-mode account** appears only when the app is connected to a local devserver: it signs in the test-mode account with that email. See [Test mode and live mode](../../concepts/test-and-live-mode/).
- The line at the bottom shows which API the app is connected to.

If sign-in fails, see [Troubleshooting → Signing in](../../reference/troubleshooting/#signing-in).
