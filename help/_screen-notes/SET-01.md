Open it from **Substratal Hub → Settings…** (⌘,) or from **Settings** in the sidebar.

- **Appearance:** Match System follows macOS; Light and Dark override it for this app.
- **Light theme** and **Dark theme:** five of each. The defaults are Moss Paper and Forest Floor. When macOS uses Increase Contrast, the app uses system colours instead.
- **Connection** (Settings window only): production or a local API devserver. See [Getting Started](../../getting-started/#choose-which-api-the-app-talks-to).
